카카오톡 채널에서 보이는 모습 (예시 화면)

01 창구

손님이 이미 쓰는 곳에서 답합니다

세 창구가 같은 가게 정보와 같은 답변 엔진을 씁니다. 적혀 있지 않은 가격이나 일정은 지어내지 않습니다.

1순위

카카오톡 채널

카카오 i 오픈빌더 스킬로 연결합니다. 답이 늦어지면 "준비 중"을 먼저 보내고 이어서 답합니다.

2순위

네이버 톡톡

스마트플레이스에서 들어온 손님에게 톡톡 챗봇 API로 답합니다.

3순위

홈페이지·블로그

스크립트 한 줄을 붙이면 이 페이지 오른쪽 아래와 같은 상담 창이 생깁니다.

02 사장님 알림

문의가 오면 알림톡으로, 안 되면 문자로

손님이 문의를 남기면 사장님 휴대폰으로 바로 알립니다. 발송 비용은 사장님 솔라피 계정에서 건당으로 나갑니다.

알림톡 예시
[모락 베이커리] 새 문의가 들어왔습니다.

창구: 카카오톡
이름: 홍길동
연락처: 010-0000-0000
내용: 토요일 오후 3시 케이크 2호 예약
  • 알림톡건당 13원, 실패 시 문자로 자동 대체
  • 문자단문 18원, 장문 45원
  • 대화 기록대화가 30분 멈추면 사장님 메일로 보내고 서버에서 지웁니다
  • 개인정보문의는 수집 동의를 받은 뒤에만 전달합니다
  • 서버·AI사장님 Cloudflare 무료 할당량 안에서 0원
03 설치

파일 하나 채우고 배포 한 번

자세한 순서는 GitHub README에 있습니다. 직접 하기 어려우면 Define404가 대신 설치해 드립니다.

  1. 가게 정보 쓰기store/store.md에 영업시간, 메뉴, 가격, 자주 묻는 질문을 적습니다
  2. 배포사장님 Cloudflare 계정에 npx wrangler deploy 한 번
  3. 창구 연결카카오 오픈빌더, 톡톡 파트너센터에 주소를 등록합니다
  4. 알림 연결솔라피 키와 사장님 휴대폰 번호를 넣습니다
